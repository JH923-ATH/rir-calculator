How it works
The Epley formula
e1RM = weight × (1 + reps ⁄ 30)

In the Week 1 Planner, we add your reps-in-reserve to the rep count so a hard set and an easy set of the same weight don't estimate the same max. The 1RM Calculator applies this formula directly to the reps you enter.
